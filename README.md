# RetainAI

RetainAI is an AI-powered customer churn investigation and retention planning platform.

It helps Customer Success teams:

- Identify customers at risk of churn
- Understand the main risk drivers
- Generate retention recommendations
- Create actionable intervention plans

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- FastAPI
- Python
- LangGraph
- Pydantic

## Disclaimer

All customer data used in this project is synthetic and intended solely for demonstration purposes.
